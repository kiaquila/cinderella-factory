# Knowledge

This folder stores reference material, distilled doctrine, and reusable domain
knowledge. It must not store private owner memory unless the source explicitly
belongs here and the owner approves it.

Planned starter knowledge scopes:

- `knowledge/mila/`
- `knowledge/salesman/`
- `knowledge/pediatrician/`

Do not paste full copyrighted books into knowledge files. Distill operational
principles and cite or describe the source.
