# Go To Market

## Ideal User

The initial user is the repository owner. This is a private personal system,
not a public SaaS launch.

## Alternatives

- Ad hoc ChatGPT/Codex conversations with no durable memory contract.
- One-off custom GPTs or prompt files.
- Larger agent frameworks that add runtime weight before the corpus exists.

## Differentiation

Cinderella Factory keeps agent behavior, memory scopes, and safety rules in
plain repository files, then uses PR review gates to evolve them deliberately.
It favors inspectable markdown over early platform complexity.

## Pricing Or Access Model

Private repository access only. No monetization is planned for V1.

## Acquisition Notes

No external acquisition path. The useful milestone is internal adoption: the
owner can invoke `mila`, `salesman`, and `pediatrician` with predictable
context boundaries.
