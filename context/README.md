# Context

This folder stores owner-specific context that is useful across sessions.
Context differs from knowledge: context is about the owner, preferences, and
working assumptions; knowledge is reference material or doctrine.

## Current Subfolders

- `core/`: low-risk general context for the owner and factory.
- `domains/`: domain-specific context that must be scoped before use.

Sensitive domain context should stay in the narrowest relevant file.
